# Agent instructions for this repository

Read [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md) before creating or changing Web UI
content. Reuse the templates, visualizer engine, and theme files it identifies
so new pages match the existing education courses. Edit source files in
`build/`, regenerate HTML with `python -X utf8 build/build.py`, and run
`python -X utf8 build/check.py` before reporting completion.

The parent workspace rules also apply. In particular, develop in this project
copy and leave the read-only originals under `Documents/Claude/Projects`
untouched.
